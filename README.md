# Beyond the Scoreboard

#### Description:

**Beyond the Scoreboard** is a web-based application developed to simplify and digitalize the management of college-level sports activities and attendance. Traditionally, details about sports participation and attendance were maintained manually using physical records. This project eliminates that outdated system by providing a centralized digital platform for students, faculty, and sports coordinators to manage all sports-related information efficiently.

---

### 🎯 Objective

The main goal of the project is to automate the process of tracking sports participation and attendance for students involved in extracurricular activities. The system allows students to register, submit participation details, upload certificates, and notify faculty about events. Meanwhile, sports coordinators and administrators can verify participation, update records, and manage attendance seamlessly.

---

### ⚙️ Features

* **User Registration and Login:**
  Secure authentication system for students and admins.

* **Sports Data Collection:**
  Students can submit information such as name, branch, semester, sport, and achievements.

* **Admin Dashboard:**
  Sports coordinators can view student data, manage participation, and update attendance records.

* **Automated Email Notifications:**
  Uses **PHP Mailer** to send automated emails to departments and students regarding attendance updates.

* **Interactive Interface:**
  Built with HTML, CSS, JavaScript, and Bootstrap for a clean, responsive user experience.

* **Database Integration:**
  Data is stored securely using **MySQL**, ensuring accuracy and easy retrieval of records.

---

### 🧩 System Architecture

* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Backend:** PHP, PHP Mailer
* **Database:** MySQL
* **Server Environment:** XAMPP / Apache
* **Editor:** Visual Studio Code

---

### 🖥️ Pages and Modules

1. **Home Page** – Displays project overview and navigation to other sections.
2. **Registration Page** – Allows new users to create accounts securely.
3. **Login Page** – Authenticates existing users.
4. **Sports Form** – Collects student details and sports information.
5. **Admin Panel** – Displays student records and enables attendance updates.
6. **Achievements Section** – Highlights notable sports achievements.
